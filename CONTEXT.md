# Эксперимент Jev для Codex

Термины согласованного эксперимента по выбору субагентов и оценке их работы.

## Language

**Ограниченная подзадача**:
Поручение субагенту с определённой целью, границами и критерием завершения.

**Профиль субагента**:
Одна из двух допустимых пар модели и reasoning effort: gpt-6-luna / max или gpt-6.1-sol / low.

**Рабочий контекст запуска**:
Набор сведений, передаваемый конкретному запуску субагента; исключение из него не изменяет оригиналы.

**Защищённый контекст**:
Действующие инструкции, требования и незавершённое состояние задачи, которые сохраняются независимо от оценки фильтра.

**Теневой режим фильтрации**:
Оценка возможных исключений из контекста без применения этих исключений к запуску.

**Оценка ненужности фрагмента**:
Оценка того, что фрагмент не потребуется конкретной подзадаче; порог этой оценки является настройкой фильтра, а не гарантией безопасности.
_Avoid_: confidence, гарантия удаления

**Бюджет Jev подзадачи**:
До 30 HTTP-обращений к TypeSafe, включая повторы, и до 30 секунд суммарного ожидания TypeSafe; время работы субагента учитывается отдельно.

**Критический инвариант**:
Одно из пяти требований: Scope preserved, User state preserved, Blast radius controlled, Claims are evidenced, Secrets protected.
